# Flanker 2.1.0 candidate

This local candidate applies the in-game chrome specification. It has not been published or approved for release.

Stopping or pressing Escape pauses the activity. Ending it calls the existing exit path before a result is sent, so the current session is not saved. Continuing discards an unfinished trial and presents the same trial again with a fresh response clock. Completed trials remain in the session; a pause during feedback resumes at the next trial. Background music stops while paused and restarts on continuation.
