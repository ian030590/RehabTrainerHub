# 遊戲共同介面第一批

六款遊戲在遊玩時按「停止」或 Escape 會先暫停，選「繼續」恢復，選「結束活動」才離開。中斷面板皆顯示「結束後不會保存這次紀錄。」（Ending the activity will not save this session.）。逐款檢查元件的 `exit`、`stopRuntime` 與完成回呼：離開會停止 runner 並中止 jsPsych，只有完成回呼會呼叫 `SendGameResult`；設定的保存與活動成果分開處理。

遊玩中退出全螢幕也會暫停，面板改顯示「已退出全螢幕，結束後不會保存這次紀錄。」（Fullscreen ended; ending the activity will not save this session.）。完成或主動結束時的全螢幕清理不會再觸發暫停。
