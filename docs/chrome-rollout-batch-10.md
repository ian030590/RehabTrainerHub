# 遊戲介面統一：第十批

三款遊戲各自保有設定、暫停與成果介面，色彩依各自分類設定。版本為本機候選版本，尚未發布。

## 眼動練習 `2.2.0`

手動暫停顯示「結束活動後不會保存這次紀錄。」相機中斷時顯示「相機輸入已中斷；繼續會重新開始活動，結束後不會保存這次紀錄。」結束沿用 `stopRuntime` 與 `ExitGame`，取消活動；原本 Escape 直接結束並產生部分成果的行為改為開啟暫停面板。

活動試次保留目前刺激與進度，暫停時間不計入活動時間，暫停期間眼動樣本不採集；恢復後接續刺激。驗證中被中斷的校正點作廢並重新採樣。相機中斷後重新啟動活動及校正，先前未完成的試次不保留。

## 海鷗飛行 `1.1.0`

手動暫停顯示「結束活動後不會保存這次紀錄。」相機中斷時在前面說明「相機輸入已中斷」。結束沿用 `showConfiguration`，中止當次流程，不呼叫完成流程的 `SendGameResult`。

保留目前飛行與圓環狀態，暫停期間不推進動畫、飛行或碰撞結束計時。恢復後接續飛行；若在頭部校正期間中斷，重新量測中立位置。手動暫停保留相機串流，相機中斷後先重新連線。

## 舌頭動作訓練 `2.1.0`

手動暫停顯示「結束活動後不會保存這次紀錄。」相機中斷時顯示「相機輸入已中斷；繼續前需重新校正，結束後不會保存這次紀錄。」結束沿用 `showConfiguration`，中止當次流程，不呼叫完成流程的 `SendGameResult`。

保留蘋果、分數與目前活動進度，暫停與重新校正期間不推進遊戲，也不計入舌頭維持時間。手動暫停保留相機串流與辨識器校正，忽略暫停期間的影格；若在校正採樣期間暫停，重新採樣該動作。相機中斷後重新啟動相機及三個校正動作，完成後接續原活動。
