# 遊戲活動條件與分析字典

此文件對應 `apps/rehabtrainerhub/games/*/{settings,score}.json` 與目前 runtime。JSON 是操作條件與資料投影契約，並不是標準化測驗、常模或療效證據。修改過的 ExpFactory 活動應報告本站版本及修改內容，不能直接沿用原任務的信效度。

## 資料層級

- `config` 保留當次設定。聲音、顯示品質與輸入方式是控制或干擾變項，不全是單向難度。預設的 easy/medium/hard 是類別，不是等距量尺。
- `score.rounds` 的列單位由各遊戲決定：可為刺激、一次作答、一題、一局或全程摘要。不同遊戲的列不能直接合併為相同試次。
- `score.summary` 是全程摘要，不能與逐列資料再次相加。缺測保持 `null`；未反應的 RT 不能填 0。類別代碼、題號及位置代碼不可用平均數解釋能力。
- ExpFactory 的 `Mean_RT_Ms` 目前包含所有有數值的作答，不限正確反應。條件效果應從逐列資料先分條件、正誤及遺漏，再依預先訂定的排除規則計算；不能把這個總平均當作 Stroop、Flanker 或切換成本。
- 設定毫秒是要求的時長，不自動等於實際曝光時長。只有 runtime 實際記錄的時序品質欄位才能用來排除掉幀等事件。

## 40 個活動

| 遊戲 | 可操弄條件／活動需求 | 列單位與可分析資料 | 解讀限制 |
|---|---|---|---|
| antisaccade | 目標曝光時間 | 目標與遮罩合併一次反應；鍵盤 RT、辨識正誤、遺漏、左右位置 | 遮罩反應的 RT 加上設定曝光時間，是跨兩段計時的估計；沒有量得眼跳潛時 |
| attention-network-task | 作答期限 | 刺激；正誤、RT、提示類型、相容條件、位置 | 分條件分析，不能以總平均代表注意網路效果 |
| flanker | 作答期限 | 刺激；正誤、RT、相容條件 | 相容性差值需充分有效試次與信度檢查 |
| stroop | 作答期限 | 刺激；正誤、RT、相容條件 | 語言與閱讀熟悉度影響表現 |
| go-nogo | 刺激呈現時間 | 刺激；Go/No-Go、遺漏、錯按、RT | Go 與 No-Go 分母不同，不只報總正確率 |
| stop-signal | 作答期限 | 刺激；Go/Stop、SSD、反應鍵、遺漏、條件、RT | 未提供 SSRT；需另按共識方法檢查停止成功率、Go 遺漏與模型假設 |
| n-back | 刺激曝光時間 | 刺激；負荷、是否匹配、正誤、RT、反應鍵 | 負荷為實際逐試次條件，不將曝光時間誤稱 n 值 |
| digit-span | 單項呈現時間 | 序列作答；長度、順逆序、正誤、作答時間 | 作答時間涵蓋整串輸入；不能當單鍵 RT |
| spatial-span | 單位置呈現時間 | 序列作答；長度、順逆序、正誤、作答時間 | 序列長度不是跨裝置等效的動作距離 |
| letter-memory | 單字母呈現時間 | 序列作答；序列長度、末四項位置正確數、全對 | 字母位置比對採既定文字正規化，不是語言能力測驗 |
| keep-track | 單項呈現時間 | 回憶組；類別負荷、必答項數、正確項數 | 比對目標類別末項；不保存自由文字到數值分數 |
| number-letter | 作答期限（0 不限時） | 刺激；單一／混合條件、上／下區、切換狀態、正誤、RT | 切換成本應比較混合區塊內切換與重複，首項切換狀態缺測 |
| plus-minus | 每份清單題數 | 清單；加／減／交替條件、題數、正確項數、清單作答時間 | 不是逐算式 RT；比較時間須控制清單長度及正確率 |
| tower-of-london | 每題時限 | 題目；完成、題號、題目時間、移動次數、最少步數 | 每次拿球／放球不各算一題；不以動作正確率代替解題成功 |
| connect4 | 對手選步策略 | 一局；時間、玩家／對手步數、無效操作、獲勝 | 非勝包含和局或敗局；不可解讀為未完成 |
| dots-and-boxes | 點陣大小 | 一局；步數、雙方格數、棋盤大小、時間、獲勝 | 點數與可得格數不同；非勝可能是和局 |
| hex | 棋盤大小 | 一局；雙方步數、無效操作、時間、獲勝 | 隨機對手與棋盤大小同時影響結果 |
| tic-tac-toe | 棋盤大小與連線長度 | 一局；雙方步數、無效操作、時間、獲勝 | 混合操弄不是單一難度軸；非勝可能是和局 |
| sudoku | 拉丁方陣／魔方陣／數獨、時限 | 一局；規則代碼、初始空格、棋盤大小、操作數、完成、時間 | 三種規則需分開分析；判定與預存解相同，未證明題目唯一解；errors 是填滿未匹配時的操作次數 |
| maze | 迷宮大小、時限 | 一局；移動、碰壁操作、時間、完成 | 未記最短路徑，不能直接報路徑效率 |
| memory-match | 配對負荷、時限 | 一局；配對嘗試、錯配、完成配對／總配對、時間 | 保留原始計數；隨機配置與重複暴露影響難度 |
| lights-out | 棋盤大小、打亂步數、時限 | 一局；操作數、大小、時間、完成 | 打亂步數不等於最短解長度 |
| sliding-puzzle | 棋盤大小、打亂步數、時限 | 一局；有效移動、無效移動、時間、完成 | 沒有最優解基準，不稱最優效率 |
| minesweeper | 棋盤尺寸、地雷配置條件 | 一局；大小、雷數、安全格／已開安全格、正確／錯誤旗標、時間、完成 | 展開格數不等於點擊次數；可由原始計數算揭露比例與旗標精確率，分母 0 留空 |
| reaction-time | 隨機等待區間、回合数、時限 | 一次嘗試；有效 RT、提前按鍵時間、提前反應標記 | 提前反應時間不混入有效 RT |
| whack-a-mole | 搜尋格數、目標期限、活動時間 | 事件；命中／到期／錯按、位置、命中 RT | 事件不等於獨立目標；到期時間不是 RT |
| simon-says | 目標序列長度、生命數 | 序列嘗試；長度、正誤、整串作答時間 | 重試不等於新刺激；作答時間不是單次按鍵 RT |
| asteroid-shield | 速度條件、時長、控制靈敏度 | 物件；時間、損傷、剩餘 HP、速度層級；全程阻擋／受擊／補給 | 機會數與物件種類影響遊戲分；不是動作功能分數 |
| drawing-defense | 速度／辨識条件、活動時間 | 敵人；擊敗、反應時間；全程敵人数、HP、實際設定 | 圖形辨識門檻與輸入裝置可能影響擊敗結果 |
| gesture-battler | 維持時間、相似門檻、自由／指定、敵人 HP | 成功施放；手勢碼、指定碼、相似度、時間；全程中斷數 | 成功列不能估計所有嘗試的 RT；相似度不是關節角度 |
| tongue-catch | 靈敏度、時間、邊緣目標機率 | 蘋果；位置、是否接到；全程接到／漏接、維持時間 | 攝影機偵測代理值，未量得舌力或吞嚥功能 |
| motor-cortex-rehab | 動作模式、時長、目標大小／速度倍率 | 事件；經過時間、維持、目標大小、適應層級；全程次數、可見比例 | 螢幕像素與手部可見比例不是生理活動或關節量角 |
| every-ball-response | 混合刺激條件、回合数 | 刺激；層級、正誤、RT、注視時長；漏反應／錯動作等 | 各種失誤用各自機會數，不能由總遊戲分推定抑制能力 |
| driving-rehab | 條件、輸入方式、渲染品質、閃光選項 | 全程摘要；RT、有效／全部事件數、碰撞、偏離、FPS | 此 score 尚非逐危險事件資料；不能支援事件條件效果或判定真實駕駛能力 |
| gabor-patching | 活動時間、刺激條件、目標數上限 | 全程摘要；取得目標數、遊戲分、經過時間 | 沒有階梯閾值資料，不代表對比敏感度 |
| hart-chart | 交替次数、字表大小 | 全程摘要；目標數、嘗試、提示、正確比例、時間 | 點選表现，不是調節幅度或標準視力 |
| moving-card | 選項數、移動間隔、物理尺寸、回合数 | 目標；正誤、RT、嘗試、錯選 | RT 可包含多次錯選後終於選對的時間；物理尺寸取決於校正 |
| oculomotor-training | 路徑、速度、軸向、干擾、大小、攝影機選項與校正 | 全程摘要；時長、目標、FPS、凝視樣本、距離、首次注視、AOI | 攝影機估計不是已驗證眼動儀；未啟用追蹤的眼動值應缺測 |
| reading-training | 呈現速率、批次片段數、對比、固定／隨機文章 | 理解題；題號、選項／正確選項、RT、正誤；摘要另記文章、語言、完整呈現、片段數 | 刺激速率不是量得閱讀速率；中英文分詞不同；重複材料有熟悉效應 |
| ufov | 子任務、固定／階梯停止、位置、曝光相關設定與螢幕校正 | 試次；正誤、實際／要求曝光、RT、位置、時序有效性；階梯與時序摘要 | 最短正確曝光不是閾值；階梯估計不是標準 UFOV 臨床分數 |

## 論文分析前仍需完成

本次屬於資料可追溯性與操作條件修正。研究仍需固定軟體／刺激版本，事前定義主要結果、分母、排除及中止規則，保存實際輸入方式與裝置資訊，並用研究樣本檢驗重測信度、效度、天花板／地板效應及速度—正確率取捨。此儲存契約沒有為所有遊戲新增逐動作軌跡、亂數種子、裝置延遲校正或個案臨床資料；需要這些資料的研究設計尚不能只用目前 score 完成。
