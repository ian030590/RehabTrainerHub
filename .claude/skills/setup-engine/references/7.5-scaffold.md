# /setup-engine: Verify Workspace

Read the selected game's package.json, Vite entry, public/game.json, runtime
and scripts/check-<gameId>-*.test.mjs. Do not regenerate existing workspaces.
New-game creation requires a separate authorized team task, its mandatory GDD
at every workflow level, failing behavior tests first and self-contained dependencies.

Never create root src/, Assets/, Source/, native-engine projects or new CI
workflows here. Use the repo's root test:ci entry. Prototypes stay outside the
game code root. Platform/other-game directories require explicit scope.
