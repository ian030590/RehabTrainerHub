# Hub icon font

`material-symbols-hub.woff2` is a 10,172-byte subset of Google's Material Symbols Outlined, under Apache-2.0 (see LICENSE.txt).

Source: [Google Material Symbols](https://github.com/google/material-design-icons), fetched through the [official font subset endpoint](https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,400,0,0&icon_names=account_circle,calendar_month,check_circle,checklist,clinical_notes,close,download,error,exercise,explore,extension,groups,help,home,info,lock,menu_book,monitoring,navigation,person_off,play_arrow,radio_button_unchecked,refresh,schedule,search,search_off,self_improvement,sports_esports,table_view,task_alt,tune,warning&display=block) on 2026-11-10.

This preserves the existing Hub glyphs while serving them locally, including in the Hub PWA precache. It does not add a dependency to any R2 game. When adding a new Hub symbol, include it in the subset and verify it with external font services blocked.
